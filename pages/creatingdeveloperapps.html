Creating Developer Applications

Learn how to register a developer application on Nokva Marketplace to access REST APIs, handle OAuth2 authentication, and manage merchant webhooks.

Prerequisite: You must have a registered Merchant or Developer account on Nokva Marketplace before registering third-party apps.

Step 1 Access the Developer Portal

Navigate to your account dashboard and select Developer Apps under the Integrations menu, or visit /developer/apps directly.

Step 2 Register Your App

Click on + Create New Application and fill out the required application metadata:

  • App Name: The public title of your integration (e.g., Nokva Inventory Sync Tool).
  • App Description: Your main application description or marketing description.
  • OAuth Redirect URI: The callback URL where authorization codes will be delivered (e.g., https://yourapp.com/api/callback).

Step 3 Retrieve Client Credentials

Once registered, the developer dashboard will generate a unique pair of credentials:

  • Client ID — Public application identifier.
  • Client Secret — Confidential key used to request access tokens.
Security Warning: Never expose your Client Secret in public Git repositories or frontend client-side code!

Step 4 Authenticate with API Access Tokens

Exchange your client credentials for a bearer token via the Nokva Authentication API endpoint:

POST /api/v1/auth/oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials
&client_id=YOUR_CLIENT_ID
&client_secret=YOUR_CLIENT_SECRET
&scope=read:products write:orders

Response containing your active bearer access token:

{
  "access_token": "nokva_at_9876543210abcdef...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "read:products write:orders"
}

Step 5 Make Authenticated API Calls

Pass your token in the Authorization header on all subsequent API requests:

curl -X GET "https://api.nokva-marketplace.com/v1/products" \
  -H "Authorization: Bearer nokva_at_9876543210abcdef..." \
  -H "Accept: application/json"
