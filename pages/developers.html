Platform API Reference

Integrate Nokva Marketplace product lists and order status updates directly into your external kitchen display systems or apps.

GET /v1/products

Retrieve a list of all currently available gourmet products, their pricing, description, and status tags.

POST /v1/orders

Place an order for selected gourmet items on behalf of a validated user session.

Example Request

# Fetch all products using curl
curl -X GET "https://api.github.com/repos/aidasofialily-cmd/nokva-marketplace-api/" \
  -H "Authorization: Bearer "YOUR_API_KEY"

Example JSON Response

{
  "status": "success",
  "products": [
    {
      "id": "prod_01",
      "name": "Artisan Cheeseburger",
      "price": 12.50,
      "badge": "Fresh"
    }
  ]
}
